КАЛЬКУЛЯТОР СКОРОСТИ ПОЕЗДА РЖД — Android-проект

Это исходный проект приложения для Android. Сам APK в этот архив не включён: в среде подготовки отсутствуют Android SDK и Gradle, необходимые для компиляции.

Как получить APK:
1. Установите Android Studio с официального сайта: https://developer.android.com/studio
2. Распакуйте архив.
3. В Android Studio выберите Open и укажите папку RZDAndroid.
4. Дождитесь синхронизации Gradle и установите Android SDK 35, если IDE предложит.
5. Для сборки APK выберите Build > Build Bundle(s) / APK(s) > Build APK(s).
6. APK обычно появится в app/build/outputs/apk/debug/app-debug.apk.

Приложение работает локально, интернет-разрешение не требуется. Внутри используется WebView и HTML-калькулятор.

Важно: это независимый калькулятор, не официальное приложение ОАО «РЖД». Для официальной отчётности проверяйте применимую методику расчёта.

Сборка через GitHub Actions без установки Android Studio на компьютер:
1. Создайте новый репозиторий GitHub и загрузите в него содержимое папки RZDAndroid (включая скрытую папку .github).
2. Откройте вкладку Actions и запустите workflow “Build Android APK” кнопкой Run workflow.
3. После успешной сборки откройте результат запуска workflow и скачайте artifact “RZD-Speed-Calculator-APK”.
4. Распакуйте скачанный artifact на телефоне или компьютере — внутри будет app-debug.apk.
Примечание: для загрузки проекта на GitHub потребуется аккаунт; сборка выполняется на серверах GitHub Actions.
